# PROCOACH UI prototype

This folder contains the modernized PROCOACH frontend prototype.

## Current state
- Single-file HTML/CSS/JS prototype
- Modern UI, modal dialogs, lightweight community-chat demo
- Community chat and profile are stored in the current browser only

## Local testing
Open `index.html` in a modern browser.

## Important
The chat is a local demo, not a real-time multi-user chat. A shared community will require a backend, user authentication, persistent database, and moderation.
